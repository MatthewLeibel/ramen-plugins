# RAMen plugins

[RAMen](https://getramenai.com) plugins for Claude.

- [ramen-memory](ramen-memory): one memory for Claude and ChatGPT. Claude saves what you tell it and looks it up when
  it matters, across chats, devices and apps.

Install in Claude Code:

    /plugin marketplace add MatthewLeibel/ramen-plugins
    /plugin install ramen-memory@ramen
